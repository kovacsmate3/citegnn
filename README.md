# CiteGNN

This repository is a mirror of a four-person course project for the MSc Graph
Neural Networks course at ELTE (Eötvös Loránd University), spring 2026, by
Sándor Baranyi, Máté Kovács, Adorján Nagy-Mohos and Balázs Bordács.
The code and documents are released under the MIT License (see `LICENSE`).

Link prediction on citation networks (Cora, PubMed) under the **HeaRT** evaluation
protocol from Li et al. (NeurIPS 2023), *"Evaluating Graph Neural Networks for Link
Prediction: Current Pitfalls and New Benchmarking"*.

The previous random-positive / random-negative pipeline based on
`torch_geometric.transforms.RandomLinkSplit` has been retired. All evaluation now
uses a **single fixed 85/5/10 split** with **K = 500 hard negatives per positive**
generated by combining Resource Allocation, Personalized PageRank and node-feature
cosine similarity via Borda's `min` aggregation.

Current scope:

- datasets: `Cora`, `PubMed`
- task: citation link prediction
- framework: PyTorch Geometric
- package manager: `uv`
- status: HeaRT split + ranking metrics + full baseline suite + structural-PE ablation

| Node2Vec | 3.38 | 7.01 | – | – |
| Feature-only MLP | 1.33 | 0.95 | 0.54 | 0.16 |
| GCN | 4.53 | 10.23 | 3.38 | 6.52 |
| GraphSAGE | 5.51 | 13.83 | 3.07 | 5.73 |
| GAT | 12.49 | 29.17 | 2.29 | 3.47 |

**Retired midterm evaluation (`RandomLinkSplit`, random negatives).** Test ROC-AUC in
percent, taken from `results/legacy_random_neg/`. Cora: mean ± sample standard
deviation over 4 seeds (7, 13, 42, 67). PubMed: 1 seed (42).

| Method | Cora ROC-AUC (4 seeds) | PubMed ROC-AUC (1 seed) |
| --- | ---: | ---: |
| Common Neighbors | 66.73 ± 0.47 | 61.72 |
| Adamic-Adar | 66.77 ± 0.44 | 61.72 |
| Personalized PageRank | 78.85 ± 0.68 | 81.37 |
| Node2Vec | 68.55 ± 2.04 | 60.96 |
| Feature-only MLP | **82.90 ± 1.32** | **93.49** |
| GCN | 68.84 ± 1.55 | 87.66 |
| GraphSAGE | 52.33 ± 3.57 | 78.57 |

Under the retired protocol, random negatives scored by ROC-AUC, the feature-only
MLP was the best model on both datasets. Under HeaRT it collapses to 1.33% MRR on
Cora and 0.54% on PubMed, because the hard negatives are partly chosen by
node-feature cosine similarity, the very signal the MLP relies on. Personalized
PageRank is the strongest implemented model on both datasets, and GAT is the
strongest trainable model on Cora. Common Neighbors and Adamic-Adar reproduce
Table 4 of Li et al. within about 0.5 MRR points on Cora, and all three heuristics
are within about 0.3 on PubMed. The exception is Personalized PageRank on Cora
(20.01% against the paper's 13.34%), which the report attributes to the
power-iteration PPR implementation. The full discussion is in
`report/citegnn-report.tex`.

**Reproduction.** A CPU rerun of the sweep in November 2026, with the recorded
configurations, is in `reproduction/cpu-2026-11/`. On a laptop CPU the Cora sweep
took 33 minutes and the PubMed sweep 89. The heuristic rows reproduce exactly on
both datasets. The trainable models aren't bit-deterministic across runs: on
PubMed they landed within 0.13 MRR points of the table above, on Cora within 1.3
(GAT 13.63, GraphSAGE 6.45, GCN 3.43). The PubMed ranking is unchanged, and so are
the Cora top ranking and the structural-PE conclusion.

## Environment

The shared project configuration defaults to CPU PyTorch wheels through `uv`.

Key points:

- Python target: `>=3.14`
- package manager: `uv`
- default PyTorch source: `https://download.pytorch.org/whl/cpu`

Install the default environment:

```bash
uv lock
uv sync
```

Run the unit-test suite:

```bash
uv run python -m compileall src scripts
uv run mypy src scripts
PYTHONPATH=src uv run coverage run -m unittest discover -s tests -v
uv run coverage report
```

GitHub Actions runs the same checks on every push to `main` and on pull requests
(`.github/workflows/ci.yml`, mirroring the team's `.gitlab-ci.yml`).

## CUDA Override

The repository is intentionally configured for CPU by default so CI and local
development stay predictable. To switch to CUDA wheels, change `tool.uv.sources`
in `pyproject.toml` to point at the relevant index (e.g. `pytorch-cu128`),
re-`uv lock`, then `uv sync`.

## HeaRT pipeline

### 1. Build the split (one-time, cached on disk)

```bash
python scripts/build_heart_split.py --dataset Cora --seed 1 --K 500
python scripts/build_heart_split.py --dataset PubMed --seed 1 --K 500
```

This loads the Planetoid dataset, computes the canonical undirected edges,
splits them 85/5/10 deterministically, builds the symmetric training graph,
runs personalized PageRank for every val/test endpoint, and generates the
`[P, K]` HeaRT hard negatives. The artifact is written to
`artifacts/heart/<dataset>_seed<S>_K<K>_heart.pt`.

### 2. Run individual baselines

```bash
# Heuristics: Common Neighbors, Adamic-Adar, Personalized PageRank
python scripts/run_heuristic_baselines.py \
  --split-path artifacts/heart/cora_seed1_K500_heart.pt

# Node2Vec (random walks + skip-gram + logistic edge classifier)
python scripts/run_node2vec_baseline.py \
  --split-path artifacts/heart/cora_seed1_K500_heart.pt

# Feature-only pairwise MLP
python scripts/run_feature_only_baseline.py \
  --split-path artifacts/heart/cora_seed1_K500_heart.pt

# GCN / GraphSAGE / GAT
python scripts/run_gnn_baselines.py \
  --split-path artifacts/heart/cora_seed1_K500_heart.pt --method all

# Just GAT with explicit attention-head count
python scripts/run_gnn_baselines.py \
  --split-path artifacts/heart/cora_seed1_K500_heart.pt --method gat \
  --gat-heads 4 --gat-attention-dropout 0.1

# GCN / GraphSAGE / GAT + structural PE (log-degree + Laplacian eigenvectors -- RQ3)
python scripts/run_gnn_baselines.py \
  --split-path artifacts/heart/cora_seed1_K500_heart.pt --method all \
  --use-structural-features --num-laplacian-eigvecs 10
```

Every baseline writes one JSON file to `results/<dataset>/<method>_seed<S>.json`
containing both ranking metrics (MRR, Hits@{1,3,10,100}) and the auxiliary
classification metrics (ROC-AUC / AP / F1 / etc.) that HeaRT recommends against
using as primary signals.

### 3. Run the full sweep on one dataset

```bash
python scripts/run_all_heart.py --dataset Cora --seed 1
python scripts/run_all_heart.py --dataset PubMed --seed 1
```

The trainable baselines use the configurations behind the reported numbers: the
`params` recorded in `results/<dataset>/*_seed1.json`, collected in
`RECORDED_CONFIGS` at the top of the script (a unit test keeps the two in sync).
`--gnn-epochs`, `--gnn-eval-every`, `--gnn-patience`, the `--feature-only-*`
options and `--node2vec-epochs` override one field for every model of that
family. Use `--skip` to leave specific baselines out, e.g.
`--skip node2vec gnn_pe`. The single-baseline scripts in step 2 keep their own,
untuned defaults.

### 4. Aggregate + compare to the published HeaRT numbers

```bash
python scripts/aggregate_heart_results.py
```

Reads every JSON in `results/<dataset>/`, groups by method, computes mean ± std
across seeds, and writes a Markdown summary at `results/HEART_RESULTS.md` that
includes the values reported in **Table 4 of Li et al. (NeurIPS 2023)** for
side-by-side comparison.

## Notes

- HeaRT only changes the **evaluation** protocol. Training still uses random
  negatives drawn fresh per epoch (Section 4.2 of the paper). The training
  graph is the symmetrized edge index of the 85% training positives.
- For PubMed, building the split takes about 10 minutes on CPU because PPR is
  computed for every val/test endpoint. The artifact is cached on disk; rerun
  with `--rebuild-split` to regenerate.
- Negatives at evaluation time are *per positive*: for each held-out edge
  `(a, b)`, K/2 negatives are anchored on `a` (`(a, v_j)`) and K/2 on `b`
  (`(u_j, b)`). MRR / Hits@K rank the positive against its K negatives using
  average tie ranking, so tied positives and negatives receive their average
  rank rather than automatically favouring the positive.
